# Content Migration Map

Milestone 1 creates the canonical Custom Review Capture System content model only. The current page may still render legacy campaign sections until the integration milestone.

## Final Rule

No campaign-era phrase below the frozen ticker is allowed in the final page. This includes `campaign wave`, `activation schedule`, `audience matching`, `local activation`, `campaign allocation`, `campaign target`, `eligible review outcomes target`, `Foundation Wave`, `Momentum Wave`, `monthly campaign reporting`, `free coffee activation`, `client campaign`, and `experience page` as the primary product.

The word `campaign` may remain only inside the frozen header, hero or ticker copy.
